VERSION 2 · DEPLOYMENT GUIDE

Connect your election.

Deploy a fresh contract for this version, then configure its frontend.

1. Deploy in Remix

  1. Open Remix. Create CampusVoting.sol using this project's file in contracts.
  2. Compile with Solidity 0.8.24. Enable optimization with 200 runs. For the same compiler settings used in local checks, select EVM Paris.
  3. Select Sepolia and your intended admin account in MetaMask. The admin needs test ETH.
  4. In Deploy & Run, select the injected MetaMask provider. Check the network and account, deploy CampusVoting, and approve the transaction.
  5. Copy the contract address. The deploying wallet is the preassigned electoral admin.

2. Configure Version 2

Open frontend/script/config.js and replace the address placeholder: 

address: "YOUR_NEW_DEPLOYED_CONTRACT_ADDRESS"

Record the same address in docs/deployed-contract-address.txt. Use the included contract, which supports registration and permanent closing.

If using another test network, change chainId, network, and rpc together in config.js. Do not put private keys or secret API keys in frontend files.

3. Run the frontend

Open frontend/html/index.html using VS Code Live Server, or run this from the project root: 

npx serve frontend

Open /html/index.html at the printed local address. Use a desktop browser with MetaMask installed.

4. Test with three accounts

  1. Admin: add Juan Dela Cruz and Maria Santos for Student Council President.
  2. Accounts 2 and 3: connect and submit their voter registrations.
  3. Admin: verify each student and authorize the two wallet addresses, then start voting.
  4. Account 2: log in and vote for Juan. Account 3: log in and vote for Maria.
  5. Try voting again with Account 2. The interface and contract must prevent it.
  6. Admin: close voting permanently. Check the final table: one vote each and two total.

Wallets, transactions, vote events, and counts are public blockchain records. This classroom app does not provide a secret ballot. The admin must approve only one wallet per real student.

Deployment and actual MetaMask signing are performed by your group. See README.md for the full checklist and contribution table.
