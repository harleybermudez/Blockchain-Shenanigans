 114        <h1>Connect your election.</h1>
 115        <p>
 116          Deploy a fresh contract for this version, then configure its frontend.

 118        <section>
 119          <h2>1. Deploy in Remix</h2>
 120          <ol>
 121            <li>
 122              Open
 123              <a
 124                href="https://remix.ethereum.org"
 125                target="_blank"
 126                rel="noopener noreferrer"
 127                >Remix</a
 128              >. Create <code>CampusVoting.sol</code> using this project's file in
 129              <code>contracts</code>.
 130            </li>
 131            <li>
 132              Compile with Solidity <code>0.8.24</code>. Enable optimization with
 133              200 runs. For the same compiler settings used in local checks,
 134              select EVM Paris.
 135            </li>
 136            <li>
 137              Select Sepolia and your intended admin account in MetaMask. The
 138              admin needs test ETH.
 139            </li>
 140            <li>
 141              In Deploy &amp; Run, select the injected MetaMask provider. Check
 142              the network and account, deploy CampusVoting, and approve the
 143              transaction.
 144            </li>
 145            <li>
 146              Copy the contract address. The deploying wallet is the preassigned
 147              electoral admin.
 148            </li>
 149          </ol>
 150        </section>
 151        <section>
 152          <h2>2. Configure Version 2</h2>
 153          <p>
 154            Open <code>frontend/script/config.js</code> and replace the address
 155            placeholder:
 156          </p>
 157          <pre><code>address: "YOUR_NEW_DEPLOYED_CONTRACT_ADDRESS"</code></pre>
 158          <p>
 159            Record the same address in
 160            <code>docs/deployed-contract-address.txt</code>. Use the included
 161            contract, which supports registration and permanent closing.
 162          </p>
 163          <p>
 164            If using another test network, change <code>chainId</code>,
 165            <code>network</code>, and <code>rpc</code> together in config.js. Do
 166            not put private keys or secret API keys in frontend files.
 167          </p>
 168        </section>
 169        <section>
 170          <h2>3. Run the frontend</h2>
 171          <p>
 172            Open <code>frontend/html/index.html</code> using VS Code Live Server,
 173            or run this from the project root:
 174          </p>
 175          <pre><code>npx serve frontend</code></pre>
 176          <p>
 177            Open <code>/html/index.html</code> at the printed local address. Use a
 178            desktop browser with MetaMask installed.
 179          </p>
 180        </section>
